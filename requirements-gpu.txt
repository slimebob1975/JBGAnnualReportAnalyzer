# CUDA-bygget av torch installeras inte harifran, utan av
# scripts\Ensure-TorchBuild.ps1. Filen finns kvar som dokumentation av vad
# som behovs och varfor.
#
# Tva saker gor det har krangligare an en vanlig pinne:
#
# 1. Processor- och CUDA-hjulen har samma versionsnummer. pip ser darfor
#    "torch==X already satisfied" och hamtar ingenting, hur ratt indexet an
#    ar. Det kraver --force-reinstall.
#
# 2. Vilket CUDA-index som har ett hjul for en viss torch-version gar inte
#    att rakna ut. cu124 visade sig bara ha torch 2.6.0 medan pinnen var
#    2.14.0. Skriptet provar darfor flera index, nyast forst.
#
# Versionen tas ur requirements.txt, sa att de tva inte kan glida isar.
# Manuellt motsvarar det:
#
#     pip install --force-reinstall --no-deps \
#         --index-url https://download.pytorch.org/whl/cu128 torch==2.14.0
#
# https://download.pytorch.org/whl/torch visar vilka hjul som finns.
