# Torch byggd för CUDA, för maskiner med ett grafikkort.
#
# Installeras OVANPÅ requirements.txt och efter den:
#
#     pip install -r requirements.txt
#     pip install -r requirements-gpu.txt
#
# Startskriptet gör det i den ordningen av sig självt när det hittar ett kort.
#
# Varför en egen fil: PyPI:s torch-hjul för Windows är processorbundna, och
# CUDA-bygget ligger på ett eget index. Att peka om indexet i requirements.txt
# skulle tvinga på varje maskin ett 2,5 GB stort hjul som inte går att använda
# utan drivrutiner.
#
# Vinsten är måttlig men verklig: maskeringens NER-steg gick från omkring fem
# sekunder till 1,2 per dokument. Resten av maskeringen är pdf-arbete som
# kortet inte rör.
#
# Byt cu124 mot den version drivrutinerna stöder. "nvidia-smi" visar vilken
# CUDA-version kortet klarar.
--index-url https://download.pytorch.org/whl/cu124
torch==2.14.0
